## 架构与模块

公开版以 Spring Boot 后端为在线业务核心，负责身份、授权、目录、播放、社区、投稿、审核、商品、支付和推荐接口。MySQL 保存业务事实与事务数据；Redis 提供缓存、限流、锁和短期状态；Kafka 处理播放等异步事件；WebSocket 提供实时通知。Elasticsearch 是可选搜索适配，关闭或不可用时回退 MySQL。

Hadoop、Hive 和 Spark 承担离线分析与推荐训练，不进入在线请求的强依赖路径。Nginx 统一承接反向代理和受控媒体路由。node3 上已有媒体只能在新库公开目录准备完成后，通过受校验的清单按新库 ID 登记，不能直接复用旧数据库编号。

## 集群部署与运维

1. 先按[软件与配置](software-and-configuration.md)安装并核对 Java、Maven、MySQL、Redis、Kafka、ZooKeeper、Hadoop、Hive、Spark、Nginx 和 FFmpeg；可选组件按实际功能启用。
2. 以 `ee/` 中的脱敏配置为结构参考，通过环境变量或权限受控的本地文件注入真实地址、账号和密钥，不直接覆盖生产配置。
3. 使用 `scripts/env.sh` 统一节点和软件目录，再分别通过 `zookeeper.sh`、`hadoop.sh`、`hive.sh`、`kafka.sh`、`redis.sh`、`spark.sh`、`nginx.sh` 管理组件。`quick-start.sh`、`stop-all-services.sh` 和 `cluster.sh` 用于编排，不替代组件自身的状态与日志检查。
4. 启动顺序遵循协调服务、存储与数据库、消息与缓存、离线组件、在线后端、Nginx；停止时反向执行。每一步都应检查端口、进程、组件状态和最近日志，不能只依据脚本退出码。
5. 配置分发前先使用 `sync-sanitized-cluster-config.ps1` 生成脱敏快照；任何真实口令、私钥、媒体文件、数据库行数据和运行日志都不得提交到仓库。

## 测试与验证

公开版不包含私有环境、测试账号、业务数据或媒体，因此验证分为可在源码仓库执行的静态/构建检查和必须在授权环境完成的运行检查。

### 源码与构建

- 使用 Java 8 和 Maven 3.6.3 编译 `hao-ran-music-backend/pom.xml`，确认依赖解析与主源码编译通过。
- 对 Shell 脚本执行 `bash -n`，对 Python 脚本执行语法检查；运行训练脚本前还要核对 Python、PySpark、NumPy 和数据路径版本。
- 本公开快照不含完整前端页面，不能把前端逻辑文件存在误报为可独立构建、可部署的网站。

### 授权环境

- 身份和权限至少区分游客、普通用户、资源所有者、创作者、审核员和管理员，并覆盖正常、篡改、重放、并发和终态后操作。
- 投稿、审核、购买、退款和媒体回收同时核对响应、数据库、Redis、Kafka、文件与审计副作用。
- Kafka、Redis、Elasticsearch、node3 媒体和推荐训练分别验证正常路径、组件不可用、恢复与回退；服务端口可访问不等于业务闭环通过。
- 性能结论必须记录数据规模、并发、持续时间和分位延迟；未保存测试条件和原始结果时，不对外声明容量结论。

## 使用边界

- 本仓库只提供公开代码快照和脱敏配置示例，不提供生产数据、账号、密钥、媒体或部署担保。
- 数据集、字体、图片和媒体应单独确认许可证与再分发权利。
- 新版本技术栈、完整前端和后续私有实现不在本公开快照的承诺范围内。
